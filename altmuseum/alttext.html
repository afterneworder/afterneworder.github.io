Alt text is a contraction of ‘Alternative Text’. It is a written description of an image online. It can be used in the cases of using text based browsers, experiencing the web through sound or when an image cannot be loaded.

An image description can never be perfectly objective. Alt text can vary depending on how the writer perceive and express the image. Also, it is necessary to be differentiated depending on the context where the image is used.

An alt text provided by Alt Museum is also a single example of many other possible image descriptions. If you have any other interpretation, please contact us through email.
