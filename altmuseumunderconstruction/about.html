Alt Museum provides alt texts of open access artworks from international museums.

There is no way to describe an image in a perfect and absolute sentence. Every image needs several interpretations to be described elaborately.

An alt text provided by Alt Museum is also a single example of many other possible image descriptions. Anyone can contribute by leaving comments if they have different interpretations of the featured art works.

Alt Museum supports individuals and institutions that realize the value of the open web.
